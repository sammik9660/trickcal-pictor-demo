# 트릭컬 테마극장 생성기 개선판 — 공개 데모 준비본

원본은 [Acherium의 trickcal-cg-generator](https://github.com/acherium/trickcal-cg-generator)입니다. 이 폴더는 개선판의 정적 웹 실행 파일만 모은 검토용 사본입니다. 원본 제작자의 공개 배포 허락을 확인한 뒤 게시하세요. 원본 저장소에 명시적 LICENSE 파일이 확인되지 않아 이 사본에 임의의 라이선스를 붙이지 않았습니다.

## 실행

정적 웹 호스팅의 루트에 이 폴더 내용을 놓으면 `index.html`이 시작 페이지입니다. Python 서버로 로컬 확인할 때는 이 폴더에서 `python -m http.server 8766 --bind 127.0.0.1`을 실행하고 `http://127.0.0.1:8766/`을 엽니다. 빌드 도구나 별도 서버 API는 필요하지 않습니다.

GitHub Pages에서는 이 폴더 내용을 저장소 루트에 올리고 **Settings → Pages → Deploy from a branch → main → /(root)**를 선택합니다. `.nojekyll` 파일을 포함했습니다. 검색 엔진 색인은 요청하지 않지만, GitHub Pages 주소와 공개 저장소의 파일은 링크를 아는 누구나 볼 수 있습니다.

프로젝트 JSON은 사용자가 브라우저에서 직접 열 수 있습니다. `?project=파일.json`은 호스팅된 같은 출처의 JSON만 읽으며, 이 데모 폴더에는 개인 프로젝트 JSON을 넣지 않았습니다. 등록한 표정 이미지와 폴더 선택 기록은 해당 브라우저의 저장 공간에 보관됩니다. 브라우저의 파일·폴더 선택 API 지원 여부에 따라 사용 가능한 선택 방식이 달라질 수 있습니다.

## 공개 파일 범위

원본의 추적된 정적 실행 파일과 개선판에 필요한 `scripts/modules/zipStore.js`만 포함했습니다. 제작 스크립트, 대본, 연출 레시피, 기존 프로젝트 JSON, 사용자 등록 이미지, 로컬 서버 실행 파일, Git 기록은 포함하지 않았습니다. 원본 사이트 및 로컬 서버를 가리키던 공유 메타데이터와 워터마크 검사 경로는 배포 주소에 종속되지 않도록 정리했습니다.
